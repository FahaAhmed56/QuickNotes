# QuickNotes ✦

A minimal, responsive notes app built with vanilla HTML, CSS, and JavaScript.

## Features
- Create notes with a title and content
- Pin important notes
- Search titles and note content
- Copy notes to the clipboard
- Delete individual notes
- Export all notes as a JSON backup
- Save notes in browser localStorage
- Responsive desktop and mobile layout

## Tech stack
HTML5 · CSS3 · Vanilla JavaScript · Browser APIs

## Run locally
1. Clone or download this repository.
2. Open `index.html` in a modern browser.

No dependencies, build tools, server, or API keys are required.

## Privacy
Notes stay in local storage in the browser on the device being used. Export a JSON backup before clearing browser data. The app does not send notes to a server.
